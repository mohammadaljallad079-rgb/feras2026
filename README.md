# STARTUP — Safir Holding Platform

Implementation repository for the Arabic-first holding company platform.

Authoritative design reference: `platform-design-ar.pdf` (32 pages), supplied by the project owner. The reference governs the **platform UI**, not the public holding website.

Approved branding asset: `assets/brand/holding-logo.png` (original supplied PNG, unchanged).

## Implementation rule
Rebuild the application from scratch against the owner's PDF reference, including page-by-page design parity, content, roles, permissions, workflows, backend, PostgreSQL schema, AR/EN locale support, light/dark modes, responsive design, and end-to-end tests. Never invent missing text or features as if they appeared in the PDF. Public website design requires a separate approved specification.
